Comparative Analysis

Project 1 - The Useless Web

The useless website is 'curing' boredom by randomly taking the user to a website that one can experiment with when one is bored. The interface is fairly simple with the button showing desperation with the word 'please' with two arrows pointing to it. There are also two ads that play on the screen.

Project 2 - Zoom Quilt

Zoomquilt is a infinite zoom of a digital masterpiece that a user can look at for a long time. Because each theme of the painting is so detailed there is always something new to notice. I would prefer going to this website when I'm bored because it allows you to be aware of your surroundings.
